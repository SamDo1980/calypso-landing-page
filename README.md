# Calypso Yachts website

Single-page, four-language (Vietnamese, English, Russian, Japanese) website for Calypso Yachts.

- `index.html`: the whole site (HTML, CSS, JS, translations)
- `images/`: photos (R30 project, shipyard, portfolio)

Open `index.html` in a browser, or host the folder on any static host (GitHub Pages works).
